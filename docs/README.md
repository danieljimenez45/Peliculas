## Cómo usar estos apuntes

1. **Estudiar en orden** si es la primera vez (1 → 9).
2. **Repasar por temas** antes del examen según lo que más te cueste.
3. **Abrir los proyectos** (DWES 25-26 y PELICULAS REPO) y seguir los ejemplos en el código.
4. **Practicar** creando un CRUD pequeño (una entidad, controller, service, repository) y luego añadir paginación, filtros y tests.
